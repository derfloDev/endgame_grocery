# Local app fonts

These WOFF2 files are the Latin and Latin Extended web subsets of the app's current Google Fonts families. The font faces use `font-display: swap` and are included in the service worker precache so installed copies remain typographically complete offline.

| Family | Weights used | Subsets | Source |
| --- | --- | --- | --- |
| Exo 2 | 400–700 | Latin, Latin Extended | Google Fonts `exo2` (v26) |
| Orbitron | 400–800 | Latin | Google Fonts `orbitron` (v35) |
| JetBrains Mono | 400–600 | Latin, Latin Extended | Google Fonts `jetbrainsmono` (v24) |
